# Madani Sher | Portfolio

Personal portfolio website of **Madani Sher**, BS Information Technology student at **Shaikh Ayaz University**.
Built with HTML, CSS and JavaScript only (no frameworks).

## Features
- Animated gradient background and glowing profile ring
- Typing effect for roles
- About, Education timeline, Skills, Projects and Contact sections
- Skill bars and counters animate when you scroll
- Light / dark theme button
- Fully responsive (mobile, tablet, desktop)

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | Design, colors and animations |
| `script.js` | Typing effect, scroll animations, theme button |
| `README.md` | Project description |

## How to edit
1. Open the folder in VS Code.
2. In `index.html`, replace `your-username` and `your.email@example.com` with your real GitHub, LinkedIn and email.
3. Change the project cards to your own projects and links.
4. Update college details in the Education section.
5. Change colors at the top of `style.css` (`:root`).

## Run locally
Double-click `index.html` to open it in your browser.

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `portfolio`).
2. Upload all four files.
3. Go to **Settings > Pages**, choose branch `main` and folder `/ (root)`, then Save.
4. Your site will be live at `https://your-username.github.io/portfolio`.
